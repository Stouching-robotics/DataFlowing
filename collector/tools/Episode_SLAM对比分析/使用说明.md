# Episode SLAM 轨迹对比分析工具

对比**同一段录制、不同处理参数**(如不同视频压缩 CRF)得到的 SLAM 轨迹,
量化轨迹间差异:RPE / ATE / 逐帧偏差 / 跟踪完整度。

## 目录内容
| 文件 | 作用 |
|---|---|
| `analyze_episode_crf.py` | 分析主程序(纯 Python, 单文件) |
| `run.sh` | Linux / macOS 一键运行脚本(自动装依赖) |
| `运行(Windows).bat` | Windows 一键运行脚本 |
| `requirements.txt` | 依赖清单 |
| `使用说明.md` | 本文件 |

## 环境要求
- Python 3.8+
- 依赖: `numpy`、`matplotlib`(首次运行会自动安装)

## 快速开始

**Linux / macOS**
```bash
./run.sh /路径/episode_00009.zip.new /路径/episode_00009_crf30.zip.new --plot
```
首次运行会在本目录创建 `.venv` 虚拟环境并自动安装依赖,之后每次直接运行。

**Windows**
双击 `运行(Windows).bat`,按提示输入 episode 目录;
或把 episode 目录直接拖到 `运行(Windows).bat` 上。
也可手动:
```bat
python analyze_episode_crf.py D:\data\episode_00009.zip.new D:\data\episode_00009_crf30.zip.new --plot
```

## 用法

```
python analyze_episode_crf.py <episode目录> [<episode目录> ...] [选项]
```

- 需要 **1 个以上** episode 目录;目录内须含 `results/trajectory/`
  (传 `episode_XXXX` 或其父目录均可,自动定位)。
- 典型的三档对比:
  ```
  ./run.sh /data/episode_00009.zip.new /data/episode_00009_crf30.zip.new /data/episode_00009_crf37.zip.new --plot
  ```

## 选项

| 选项 | 说明 |
|---|---|
| `--ref <目录>` | 指定基准目录;不指定则**两两对比**(无预设基准) |
| `--traj online\|tum\|body` | 轨迹文件类型,默认 `online` |
| `--deltas 0.5 1.0 2.0` | RPE 时间增量(秒),默认 `0.5 1.0 2.0` |
| `--outdir <目录>` | 输出根目录,默认 `crf_report` |
| `--plot` | 生成可视化图 |
| `--title "文本"` | 图标题前缀 |

**示例**
```bash
# 指定基准
./run.sh /data/A /data/B /data/C --ref /data/A --plot
# 只出文字报告, 不用图
./run.sh /data/A /data/B
# 自定义输出目录
./run.sh /data/A /data/B --outdir 输出报告 --plot
```

## 输出

**每次运行自动新建独立子目录 `run_<时间戳>/`,历史结果不会被覆盖**,可随时回看。

```
输出根目录/
└── run_20260827_154805/

    ├── summary.txt                  # 与报告内容相同,方便直接打开

    ├── traj_xy.png / traj_xz.png / traj_yz.png

    ├── dev_vs_time.png              # 逐帧偏差时间曲线

    └── tracking_ok.png              # 跟踪完整度柱状图
```

## 指标说明
- **RPE**(相对位姿误差):每隔 `Δ` 秒比较两条轨迹的帧间相对运动一致程度。平移单位 mm、旋转单位 °。衡量"两条轨迹的运动是否一致",无需坐标系对齐。
- **ATE**(绝对轨迹误差):Umeyama 刚体对齐后的平移残差(mm),衡量整条轨迹的贴合程度。
- **跟踪完整度**:SLAM 成功跟踪的帧占比(2 = 跟踪OK / 输入帧数)。
- **最大间隙**:轨迹中相邻样本的最大时间间隔(s),即跟丢时长。

## 常见问题
**Q: 图中文字显示为方框?**
A: 系统缺少中文字体。安装 Noto Sans CJK(如 `sudo apt install fonts-noto-cjk`)即可,不影响数值。

**Q: 报错找不到 `results/trajectory/`?**
A: 传入的目录必须是 episode 目录,或包含 `episode_*` 子目录的父目录。

**Q: 想换输出目录但不想每次删旧文件?**
A: 不需要删。每次运行都是新的 `run_<时间戳>/`,旧结果自动保留。
