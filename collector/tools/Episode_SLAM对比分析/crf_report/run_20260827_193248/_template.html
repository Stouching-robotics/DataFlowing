观察 · 非单调

压缩档的劣化不是单调的：CRF 34（ATE 340mm）反而比 CRF 37（176mm）更差。 基准本身只有 35.3% 跟踪率、中段有 5.2s 跟丢段，各档在该段的重建行为各不相同（SLAM 对压缩伪影的敏感度有随机性）。 可靠结论：28/30 与原档重合良好（ATE ≈ 18mm），34/37 不可用。另：本段录制整体跟踪质量偏低（35%）， 若用于正式交付，建议重录或仅截取跟踪良好的区间。
