# 手套识别 + 训练工具包

YOLO-World + RTMPose（MMPose）方案，专为戴手套（黑/灰/任意颜色）场景优化。
MediaPipe 在手套上完全失效，本方案实测检出 40/40。

## 一、安装（Windows）

双击 `setup.bat`，或手动执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe fix_clip.py
```

首次运行识别会自动下载模型（约 450MB，需联网）：
- `yolov8m-worldv2.pt` — YOLO-World 检测器
- RTMPose hand5 — 关键点模型（缓存到 `~/.cache/rtmlib/`）
- CLIP 权重 — 文本编码

## 二、识别

```powershell
# 黑手套 / 灰手套 / 任何手套
.venv\Scripts\python.exe hand_demo_mmpose.py --prompt glove

# RealSense D435 深度相机（颜色流；需先 pip install pyrealsense2）
.venv\Scripts\python.exe hand_demo_mmpose.py --prompt glove --realsense
# 多台 D435 时用 --rs-serial 指定序列号

# 图片目录 / 视频源
.venv\Scripts\python.exe infer.py --source clip.mp4
.venv\Scripts\python.exe infer.py --source D:\imgs

# 摄像头实时（D435 颜色流；UVC 用默认 --source 0）
.venv\Scripts\python.exe infer.py --realsense
.venv\Scripts\python.exe infer.py --detector runs/hand_det/weights/best.pt --realsense

# 换自己的训练模型（注意：走 --detector，不是 --weights）
.venv\Scripts\python.exe hand_demo_mmpose.py --detector runs/hand_det/weights/best.pt
```

快捷键：`q` 退出 | `a` 角度 | `s` 骨架 | `b` 检测框 | `h` 帮助
采集：`c` 抓拍单帧 | `r` 连续采集 | `m` 只存漏检帧

**无手套误检抑制**（训练模型路径自动生效）：检测置信度门槛 `--det-conf`
默认 0.45 + 关键点有效性门（RTMPose kpt 均值 ≥0.45 且 ≥15 个高置信点、
点团跨度 ≥0.3×框对角线，连续 2 帧才显示）——背景误检框解不出像样的
21 点骨架会被整框丢弃，不画框不解算。想更敏感调低 `--det-conf`。

## 三、训练

```
采集(r键) → 导出数据集 → 自动标注 → 人工复核 → 合并 → 训练 → 替换模型
```

### 1. 采集（200+ 帧，覆盖各种手势角度）

```powershell
.venv\Scripts\python.exe hand_demo_mmpose.py --prompt glove
# 按 r 连续采集，攒够 q 退出
```

### 2. 导出数据集

```powershell
.venv\Scripts\python.exe prepare_dataset.py --captures captures1 --out dataset
```

### 3. 自动标注 + 人工复核（漏检帧）

```powershell
.venv\Scripts\python.exe auto_label.py --dir to_label
.venv\Scripts\python.exe annotate.py --dir to_label
.venv\Scripts\python.exe prepare_dataset.py --merge to_label --out dataset
```

**框错帧重标**（有框但框不准的帧不进 to_label，直接开 dataset 改）：

```powershell
.venv\Scripts\python.exe annotate.py --dir dataset
# 加载旧框为初始框：c 清空重画 / 直接拖新框覆盖 / d、a 翻页自动保存
```

### 4. 训练

```powershell
.venv\Scripts\python.exe train_detector.py --data dataset/data.yaml --epochs 100 --no-augment-hsv
# 训练设备留空自动选 GPU（CUDA），也可显式 --device 0
```

### 5. 用训练好的模型

```powershell
.venv\Scripts\python.exe hand_demo_mmpose.py --detector runs/hand_det/weights/best.pt
# 或直接实时推理评估（D435）
.venv\Scripts\python.exe infer.py --detector runs/hand_det/weights/best.pt --realsense
```

## 文件清单

| 文件 | 作用 |
|---|---|
| `hand_demo_mmpose.py` | 摄像头实时识别（主入口） |
| `infer.py` | 图片/视频/摄像头识别（`--realsense` 支持 D435） |
| `world_detector.py` | YOLO-World 检测器封装 |
| `hand_common.py` | 21 点定义、角度计算、绘制 |
| `auto_label.py` | 零样本自动标注 |
| `annotate.py` | 人工标注工具 |
| `prepare_dataset.py` | 采集数据 → YOLO 数据集 |
| `train_detector.py` | 训练手部检测器 |
| `verify_pose.py` | 关键点质量验证 |
| `setup.bat` | 一键安装 |
| `fix_clip.py` | openai-clip 兼容补丁 |

## 依赖

Python 3.10+，NVIDIA GPU（CUDA 12.4）推荐。CPU 也可跑但检测 ~85ms/帧。
