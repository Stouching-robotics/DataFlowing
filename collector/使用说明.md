# DAQ 数据采集系统 · 使用说明

> 面向最终用户的操作指引与常见异常解决方案。
> 与 `start.bat` 输出的错误码（A–G）一一对应，报错时按错误码查找本页即可。

> English version: [使用说明_EN.md](使用说明_EN.md)

---

## 1. 一键部署（首次使用）

1. 从 GitLab 下载代码压缩包，解压到任意目录（建议纯英文短路径，如 `D:\collector`）。
   ⚠ 解压后请确认 `start.bat` 与 `main.py` **在同一目录**（部分解压工具会多套一层文件夹，需进入内层目录）。
2. 双击 **`start.bat`**，脚本自动完成：
   - 检查 Python → 没有就自动下载安装 Python 3.12（约 25MB，静默安装）
   - 创建虚拟环境 `venv/`
   - 安装依赖（离线 `wheels/` 包优先 → 阿里云镜像 → 清华镜像 → 官方源）
   - 依赖自检 → 自动启动主程序
3. 首次部署约 **3–10 分钟**（视网速）；之后每次双击**秒开**，不会重复安装。

> 依赖有更新时，脚本检测到 `requirements.txt` 变化会自动补装，无需手动操作。

---

## 2. 常用命令

| 命令 | 作用 |
|---|---|
| 双击 `start.bat` | 部署（按需）+ 启动主程序 |
| `start.bat reinstall` | 删除 venv 强制重装（**出问题首选**） |
| `start.bat extras` | 追加安装 mediapipe（裸手 3D 关键点）+ pyrealsense2（D435/D405 相机） |
| `start.bat extras-torch` | 追加安装 CPU 版 torch（手部关键点 RTMPose 后端） |
| `start.bat help` | 打开本文档 |

Linux 对应版：`./start.sh`，命令一致。

## 3. 主界面操作指引

> 主程序启动时会自动弹出「使用说明」窗口（从 URL 填写到录制回放上传的完整步骤），
> 可勾选「下次不再显示」；之后随时从菜单 **帮助 → 使用说明** 重新打开。
> 窗口内指南与此文档内容一致，以窗口内为准。

- **设备面板**：插入相机（UVC 摄像头 / Intel RealSense D435、D405 / 双目相机 S80C，面板显示为 FaysSense S80M）后等待约 2 秒自动出现，点击即可预览画面；触觉手套开机并开启电脑蓝牙后自动出现在「🧤 手套」组，点击即自动连接（左/右手按广播名 L/R 识别）。
- **网格布局**：拖动画面边缘与分割条调整每路画面的大小和位置。
- **录制**：每路相机有独立的「开始 / 停止」按钮。
  - **正常停止** = 保存本次录制；**异常停止** = 丢弃本次录制（录制时长实时显示在按钮上方）。
  - **视频格式**：默认自适应——录制时自动探测机器编码性能，优先 H.265/HEVC（CRF 30，体积约为 H.264 的 1/10），性能不足自动回退 H.264；上传时 HEVC 视频直接跳过二次压缩（更快、画质只损失一代）。**HEVC 视频 Windows 自带播放器打不开**：用免费 VLC 播放器打开，或安装微软商店「HEVC 视频扩展」；也可以把 `config/settings.py` 的 `RECORD_VIDEO_ENCODER` 改为 `"x264"`，之后新录制的视频即为 H.264（旧文件不变）。主程序内「回放」始终可以查看。
- **任务**：顶部选择任务后开始录制；左侧可查看录制历史并回放。
- **上传**：录制完成后可上传至服务器（服务器地址等配置见 `data/server_config.example.json`，改好后另存为 `data/server_config.json`）。
- **语言**：设置页可切换中英文界面。
- **双目相机（S80C）深度**（v1.0.11）：开启后左右目画面旁出现第三格实时深度热力图；录制时同时保存深度热力图视频（`depth/stereo_depth/stereo_depth.mp4`）与原始深度数据（`depth/stereo_depth/000001.png …`，PNG 16 位灰度、uint16 毫米；D435/D405 的深度数据同格式）。
- **高级功能**（需先运行 `start.bat extras`）：
  - D435/D405 深度相机 RGB+深度双路录制
  - 手部 3D 关键点处理（`tools/hand_3d_d435/` 等）

## 4. 常见异常与解决方案

### 4.1 错误码对照表（与 start.bat 输出一致）

| 错误码 | 现象 | 解决方案 |
|---|---|---|
| **A** | 找不到 Python / 自动安装失败 | ① 离线环境：把 `python-3.12.10-amd64.exe` 放入 `wheels/` 后重试；② 手动安装：官网下载 Python 3.12.x **64 位**，安装时勾选 **Add python.exe to PATH**；③ 已装过 Python：可能是 Microsoft Store 版干扰，在「设置-应用」卸载后装官网版；④ 已有 Python 但版本低于 3.10 同样走 ② |
| **C** | 虚拟环境创建失败 | ① 磁盘空间不足（需约 2GB）；② 杀毒软件拦截 → 目录加白名单后 `start.bat reinstall`；③ 路径过长 → 移到 `C:\collector` 之类短路径；④ 路径含特殊字符 → 换纯英文目录 |
| **C2** | 旧 venv 删除失败 | 主程序还在运行，先关闭窗口再 `start.bat reinstall` |
| **D** | 依赖下载/安装失败 | ① 网络不通 → 检查网络后重跑（已下载部分有缓存，不重复）；② 公司网络限制 → 请管理员放行 PyPI 镜像，或走离线交付（见第 6 节）；③ 杀毒/防火墙拦 pip → 白名单；④ 多次失败 → `start.bat reinstall` |
| **E** | 依赖自检失败 | ① 杀毒软件隔离了 venv 文件 → 隔离区恢复 + 白名单；② `start.bat reinstall` 重装；③ 在 cmd 运行 `venv\Scripts\python.exe -c "import main"` 看具体报错 |
| **F** | 主程序启动后异常退出 | ① 显卡驱动过旧 → 更新驱动；② 远程桌面/虚拟机 → 本地实机运行；③ Qt 平台插件错误 → `start.bat reinstall`；④ 摄像头无画面 → Windows「设置-隐私和安全性-相机」允许应用访问相机；⑤ cmd 运行 `venv\Scripts\python.exe main.py` 看具体报错 |
| **G** | 提示未找到 main.py | 解压层次不对：进入 `start.bat` 与 `main.py` 同级的内层目录再双击 |

### 4.2 摄像头相关问题

| 现象 | 解决方案 |
|---|---|
| 设备面板看不到相机 | ① Windows「设置-隐私和安全性-相机」允许桌面应用访问；② 设备管理器确认驱动正常；③ 关闭正在占用相机的软件（微信、腾讯会议等）；④ 换 USB 口（优先主板直连口/3.0 口） |
| 双目相机（S80C）与 RealSense 不能同时开启 | 属设备限制：先关闭 RealSense 设备再开启双目相机 |
| 手套组不出现设备 | 确认手套电源已开、电脑蓝牙已开启，等待面板自动刷新（约几秒）；仍无则重新开合手套电源再试 |
| 有画面但很卡 / 帧率低 | 换 USB 3.0 接口；避免使用 USB Hub 或延长线；关闭其他占用相机的程序 |
| RealSense 相机不识别 | 先运行 `start.bat extras` 安装 pyrealsense2，重新插拔相机再试 |
| 录制文件损坏 / 丢帧 | 录制时避免插拔设备；正常停止后稍等片刻再退出程序 |

### 4.3 上传相关问题

| 现象 | 解决方案 |
|---|---|
| 上传失败 / 超时 | 检查网络与服务器连通性；确认 `data/server_config.json` 地址正确（首次使用请复制 `server_config.example.json` 改名） |
| 上传显示成功但服务器上看不到 | 联系管理员检查服务器导入日志（批量导入失败会静默丢弃），并提供会话名与任务名 |
| 大文件上传慢 | 属正常现象，录制文件较大时上传需较长时间，请耐心等待 |

### 4.4 其他

| 现象 | 解决方案 |
|---|---|
| 双击 `start.bat` 被 Windows 拦截（SmartScreen 蓝色警告） | 这是浏览器下载文件的安全标记，属正常提示：点击「更多信息」→「仍要运行」；或在文件属性中勾选「解除锁定」 |
| 窗口内中文乱码 | `start.bat` 是 GBK 编码文件：不要用记事本 / VSCode 另存（默认会存成 UTF-8，导致 cmd 乱码并静默失败）；乱码时重新从 GitLab 下载原文件 |
| 杀毒软件报毒 / 拦截安装 | 一键部署会联网下载并静默安装 Python，属正常行为；将项目目录加入白名单 |
| 提示磁盘空间不足 | 清理磁盘；录制数据会随使用增长（见第 5 节） |
| 录好的视频在 Windows 播放器打不开 | 默认 H.265/HEVC，Windows 自带播放器不带解码器。**首选：安装免费 VLC 播放器直接打开**（主程序内「回放」也可正常查看）；或到微软商店安装「HEVC 视频扩展」；或把 `config/settings.py` 的 `RECORD_VIDEO_ENCODER` 改为 `"x264"` 后重新录制（只影响之后新录制的视频） |
| 录制结束提示「编码器可能跟不上，建议降低分辨率/路数」 | 机器编码性能不足：减少同时录制的路数或分辨率，或把 `config/settings.py` 的 `RECORD_VIDEO_ENCODER` 改为 `"x264"`（最快的回退编码器） |

## 5. 数据存放与备份

- **录制数据**：`data/recordings/<任务名>/<任务名>_NNNNNN/`（每路设备的 MP4 视频 + parquet 时序数据 + 元数据 JSON）
- **录制历史与上传队列**：`data/pipeline.db`（SQLite）
- **备份**：直接拷贝整个 `data/` 目录即可。

## 6. 离线环境交付（内网机器，管理员操作）

在有网的机器上生成离线安装包（建议先 `pip install uv`，Linux 开发机上
跨平台解析依赖需要它；没有 uv 时请直接在一台 Windows 机器上运行）：

```bash
python scripts/pack_wheels.py            # 仅主程序必需依赖
python scripts/pack_wheels.py --extras   # + mediapipe / pyrealsense2
python scripts/pack_wheels.py --torch    # + CPU 版 torch
```

产物为 `wheels/` 目录（依赖轮子 + Python 安装包）。**把整个 `wheels/` 拷到客户项目根目录**，
客户的 `start.bat` 会自动检测并走纯离线安装，全程不需要外网。
